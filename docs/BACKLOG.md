## ⚠ 배포 전 필수 조치 (코드는 이미 반영됨, 아래가 없으면 안 돌아감)

- [ ] **Google Sheet에 "소속팀", "환영메시지" 열 추가** — `docs/gas-code.gs`의
      `COL.TEAM`/`COL.WELCOME_MSG`가 이 헤더 텍스트를 찾습니다. 열이 없으면
      `assertHeaders_`가 실패해서 이름·출근일·담당자 자동 조회가 **전체
      입사자에 대해 통째로 깨집니다.** ("환영메시지"는 비워둬도 되지만, 열
      자체는 있어야 함)
- [ ] **실제 배포된 Apps Script를 `docs/gas-code.gs` 최신본으로 교체 후 재배포**
      — GitHub에 push하는 것과 별개로, script.google.com의 배포된 스크립트는
      **수동으로 갱신해야** 합니다. 이걸 안 하면 팀 자동 개인화가 코드상으로는
      있어도 실제로는 동작하지 않습니다.

## 기능 (중요도 순)

### 1. 웰컴 키트 미리보기
배송지 폼 위에 실제 키트 구성 이미지 배치.
"무엇을 받는지" 보여주면 폼 작성률이 올라갑니다.

### 2. 참고 정보 탭 퀴즈 (3문항)
Appical이 프리보딩의 핵심 축으로 꼽는 "인터랙티브 콘텐츠".
읽고 → 확인하는 학습 루프를 만듭니다.

### 3. 체크리스트 서버 저장
현재 localStorage라 같은 링크라도 기기를 바꾸면 진행률이 날아갑니다.
(배송지 폼 제출 여부는 이미 GAS/Sheets에 저장되어 기기 간 유지됨 — 할 일
체크리스트만 아직 로컬에만 남는 상태)
