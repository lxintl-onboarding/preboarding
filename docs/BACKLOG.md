- [ ] **Google Sheet/Apps Script 공유 설정 점검** — "링크가 있는 모든 사용자"로
      열려 있다면 "제한됨 + 개별 초대"로 전환 필요 (전용 계정 로그인 여부와 무관하게
      뷰어 접근이 됐다면 실제 개인정보가 노출된 상태일 수 있음)

## ⚠ 배포 전 필수 조치

- [ ] **Google Sheet에 "소속팀", "환영메시지" 열 추가** — 값은 비워둬도 되지만
      열 자체가 없으면 `assertHeaders_`가 실패해서 이름·출근일·담당자 자동
      조회가 **전체 입사자에 대해 통째로 깨집니다.**
- [ ] **실제 배포된 Apps Script를 `docs/gas-code.gs` 최신본으로 교체 후 재배포**
      (기존 배포 "편집 → 새 버전"으로. "새 배포"를 누르면 URL이 바뀌어서
      `index.html`의 `GAS_ENDPOINT`와 어긋납니다)
      — 재배포 후에는 화면부터 보지 말고 `GAS_ENDPOINT?t=토큰`을 브라우저로
      직접 열어 JSON에 `team`/`message` 값이 나오는지 먼저 확인할 것

## 콘텐츠 채우기

- [ ] CEO 축하 영상 링크 (현재 "환영 인사" 탭에 플레이스홀더 카드만 있음)
- [ ] "동료들의 환영 인사" — To(이름)/본문/From(소속팀) 3섹션 구조, 그리고 본문의
      3단계 폴백(환영메시지 → 이름·팀 자동 치환 템플릿 → 완전 범용 문구)까지
      코드로 완성됨 (`index.html`). 남은 건 콘텐츠뿐: 담당자가 팀별로 환영메시지를
      받아서 Sheet의 "환영메시지" 열에 채워 넣으면 그 즉시 반영됨. 메시지 요청 시
      "이름·팀명은 본문에 다시 안 넣어도 됨(자동 표시됨)"이라고 안내할 것
      (`docs/UX_IMPROVEMENT_PLAN.md` Phase 2-1 "팀/동료의 한마디" 참고)

담당자 성함·연락처는 더 이상 여기서 채울 항목이 아닙니다 — Google Sheet 행 값을
GAS가 조회해 자동으로 채웁니다 (`README.md` "새 입사자를 추가하려면" 참고).

## 기능 (중요도 순)

### 1. 웰컴 키트 미리보기
배송지 폼 위에 실제 키트 구성 이미지 배치.
"무엇을 받는지" 보여주면 폼 작성률이 올라갑니다.

### 2. 참고 정보 탭 퀴즈 (3문항)
Appical이 프리보딩의 핵심 축으로 꼽는 "인터랙티브 콘텐츠".
읽고 → 확인하는 학습 루프를 만듭니다.

### 3. 체크리스트 서버 저장
현재 localStorage라 같은 링크라도 기기를 바꾸면 진행률이 날아갑니다.
(배송지 폼 제출 여부는 이미 GAS/Sheets에 저장되어 기기 간 유지됨 — 할 일
체크리스트만 아직 로컬에만 남는 상태)
